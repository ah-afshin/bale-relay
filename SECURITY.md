# Security reporting

Security fixes target the current development branch. No older release has a
separate security maintenance commitment.

Please report vulnerabilities privately. If this repository has GitHub private
vulnerability reporting enabled, use **Security > Report a vulnerability**.
Otherwise, use a private contact method published by the maintainer,
[ah-afshin](https://github.com/ah-afshin). If none is available, open an issue
asking for a private reporting channel without disclosing the vulnerability.

Include the affected revision, impact and minimal reproduction using synthetic
data. Do not include real tokens, database URLs, secret webhook paths, complete
updates or private conversations. Avoid testing against other people's bots or
production data.

For operator configuration and privacy boundaries, see
[Configuration](docs/configuration.md) and the [deployment guide](deploy/README.md).
